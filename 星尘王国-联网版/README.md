# 星屿王国 · 放置传说 —— 联网模式

《星屿王国 · 放置传说》（原《星尘王国》）的基础联网版。保留全部本地单机玩法，
新增 **云存档 / 全服排行榜 / 全服聊天** 三项联网能力，为后续 TapTap 上架做准备。

## 目录结构

```
星尘王国-联网版\
├── server\                  # 联网后端（零依赖，仅用 Node 内置模块）
│   ├── server.js            # 后端主程序（HTTP API + JSON 文件存储）
│   ├── package.json         # npm 元数据（可选）
│   └── data\                # 运行后自动生成：users / saves / chat 数据文件
├── 星尘王国-放置传说.html              # 移动版（已内置联网模块）
└── 星尘王国-放置传说-电脑版.html        # 电脑版（已内置联网模块）
```

## 快速启动（本地跑通）

1. **启动后端**（首次）
   ```
   cd 星尘王国-联网版\server
   node server.js
   ```
   看到 `[星屿王国联网后端] 已启动: http://localhost:3000` 即成功。
   后端数据自动保存到 `server\data\` 下的 JSON 文件，重启不丢档。

2. **打开游戏**：直接用浏览器打开 `星尘王国-放置传说-电脑版.html`
   （移动版同理）。游戏检测到后端后即可联网。

3. **首次使用**：进入「设置」→「联网与云存档」→ 点 **游客登录**。
   - 游客账号自动按设备生成（同一浏览器再次打开会自动恢复登录）
   - 登录后自动开启云存档同步（每 30 秒自动上传）
   - 全服聊天：战斗页聊天窗切到「**世界**」频道即可发言

## 功能说明

| 功能 | 位置 | 说明 |
|---|---|---|
| 云存档 | 设置 → 联网与云存档 | 自动同步 + 手动「上传 / 下载」；下载会以云端覆盖本地 |
| 全服排行榜 | 排行页 → 全服榜 | 按战力排序，Top 50，15 秒刷新；登录且开启自动同步后自动上榜 |
| 全服聊天 | 聊天窗 → 世界频道 | 3 秒轮询刷新，消息保留最近 500 条 |
| 在线状态 | 设置 → 联网与云存档 | 显示登录名与连接状态；离线自动提示 |

## 接入 TapTap 登录（上架前）

联网版已内置完整的 TapTap 登录代码路径（`server.js` 中的 `/api/auth/taptap` 端点 + 前端「TapTap 登录」按钮），
但需在 TapTap 开放平台完成配置后才会生效：

1. 注册 TapTap 开发者账号，创建游戏应用，获取 **AppID / AppSecret**
2. 配置回调域名，确认 OAuth 流程
3. 启动后端时注入环境变量：
   ```
   set TAPTAP_APP_ID=你的AppID
   set TAPTAP_APP_SECRET=你的AppSecret
   node server.js
   ```
4. 按开放平台文档完成 `/api/auth/taptap` 中的 code 换 token 逻辑（代码中已标注 TODO 位置）

在配置完成前，「TapTap 登录」按钮会提示该功能为预留，游客模式可完整跑通全部联网功能。

## 局域网联机（可选）

想让手机/其他电脑连你的游戏：先查本机局域网 IP（`ipconfig` 里的 IPv4 地址，如 `192.168.1.5`），
然后在游戏「设置 → 联网与云存档」把服务器地址改成 `http://192.168.1.5:3000` 并点「保存地址」，
刷新页面即可。需确保防火墙放行 3000 端口。

## 技术说明

- **后端**：Node.js 原生 `http` 模块 + JSON 文件存储 —— 零 npm 依赖，任何 Node ≥ 16 环境直接运行
- **前端**：单文件 HTML 注入独立联网模块（`window.NET`），不改动原游戏核心逻辑
- **接口**：`/api/auth/guest`、`/api/auth/taptap`、`/api/save`、`/api/rank`、`/api/chat`、`/api/heartbeat`、`/api/health`
- **存档**：本地仍存 `localStorage`（key `stardust_kingdom_v1`），云端为服务器 JSON 文件；本地=主档，云端=同步副本
- **限流**：单账号每分钟写请求上限 30 次；存档上限 2MB；消息长度上限 120 字
